# Tarjeta de Golf

App web personal para apuntar vueltas de golf, calcular el hándicap (WHS) y ver dónde se pierden golpes. Incluye el recorrido del Club de Golf Vallromanes con distancias del libro del club.

Se instala en el móvil desde el navegador: **Añadir a pantalla de inicio**. Las vueltas se guardan solo en el propio móvil.
